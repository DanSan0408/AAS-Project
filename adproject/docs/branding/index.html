💻 Developer Quickstart & API

Incorporate the branded loading animation in any template with simple HTML or JavaScript calls:

Option A: JavaScript Programmatic API

// Show loading screen with custom operation text
IAMSLoading.show('Calculating final capstone marks...');

// Dynamically update status message during multi-stage actions
IAMSLoading.setMessage('Generating summary report...');

// Hide loading screen when operation completes
IAMSLoading.hide();

// Trigger a timed operation
IAMSLoading.trigger(2000, 'Saving assessment changes...', function() {
    console.log('Complete!');
});

Option B: Thymeleaf Reusable Fragment

<!-- Pre-rendered fragment in templates/fragments/loading_screen.html -->
<div th:replace="~{fragments/loading_screen :: loadingScreen}"></div>

<!-- Link stylesheets and controller script -->
<link rel="stylesheet" th:href="@{/css/loading.css}">
<script th:src="@{/js/loading.js}"></script>
